# Windows 报告管理工具使用说明

本目录中的工具只在 Windows 报告管理电脑运行，不推送到被检查终端。它们可以同时处理 Windows 报告和麒麟客户端上传的新格式报告。

## 1. 使用顺序

1. 将 Windows 和麒麟生成的 HTML/JSON 放在同一个报告目录。
2. 备份报告目录。
3. 把 `ftp-report-pruner-x64.exe` 放入报告目录并运行，确认后删除旧批次。
4. 把 `report-person-exporter.exe` 放入同一目录并运行，选择人员对应表。
5. 查看生成的 Excel 和 `issue-summary.log`。

## 2. 重复报告整理

程序：`ftp-report-pruner-x64.exe`

它识别：

- Windows 和新版麒麟：`verification-report_*`
- 历史麒麟：`kylin-report_*`

程序按终端身份只保留时间最新的一组完整 HTML/JSON。缺少 HTML 或 JSON 的批次、上传状态文件以及未知文件不会删除。程序先显示待删除清单，只有输入小写 `yes` 才会真正删除。

不要在没有备份的唯一报告目录中直接确认删除。

## 3. 人员问题 Excel 汇总

推荐程序：`report-person-exporter.exe`（32 位通用版）
备用程序：`report-issue-exporter-x64.exe`（仅用于确定为 64 位的管理电脑）

运行步骤：

1. 双击程序。
2. 在文件选择窗口选择人员对应表。
3. 等待生成 `person-security-issues-summary.xlsx`。
4. 查看同目录的 `issue-summary.log` 是否记录损坏、缺件或冲突报告。

人员表的文件名和工作表名称不固定。程序自动查找包含下列字段的工作表：

- 持有人字段：`持有人`、`使用人`、`姓名`、`用户`或`责任人`之一。
- `IP`。
- `MAC`。
- 可选字段：`组织机构`、`操作系统`。

支持格式：

- `.xls`：直接读取，不要求安装 Excel。
- UTF-8 `.csv`：直接读取，不要求安装 Excel。
- `.xlsx/.xlsm`：管理电脑需要安装 Microsoft Excel；不能保证时请另存为 `.xls` 或 UTF-8 CSV。

匹配顺序为 IP+MAC 完全一致、MAC 唯一匹配、IP 唯一匹配。无法唯一匹配时标记“未匹配/待核查”，不会擅自对应人员。

## 4. 输出内容

Excel 包含：

1. `终端问题汇总`：每台终端一行。
2. `人员问题汇总`：同一人员的多台终端合并并保留终端来源。
3. `统计汇总`：按平台、组织机构和风险等级统计。

汇总只保留人员、组织机构、平台、终端标识、简明问题、需复核问题、风险等级和源报告文件名，不复制命令输出、USB 日志、浏览器账号、修复动作等报告详情。

风险等级采用该终端最高等级：

- 高危：高危端口规则、防火墙、Server 服务、远程桌面或无线网络信息存在异常。
- 中危：检测到浏览器保存密码。
- 待核查：没有高危/中危异常，但存在 USB、外部连通性、读取失败等需人工确认项。
- 低危：仅存在其他已经确认的普通异常。
- 正常：没有异常和需复核项。

损坏 JSON、缺少配对 HTML、同一终端同时间戳冲突会写入日志，不进入 Excel。
